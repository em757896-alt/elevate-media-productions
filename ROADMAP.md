# Roadmap

This repo is the home of Elevate Media Productions' open-source work. The roadmap is a live
document — the goal is to make every release genuinely useful to developers, not just a showcase.

## Now

- [ ] **`elevate-web-starter` v1.0** — finalize theme tokens, section components, SEO and docs
- [ ] **CI/CD pipeline** — `svelte-check` + build running on every push and PR for `apps/web` and starters
- [ ] **Video tooling** — document `tools/video` workflow in the repo so anyone can generate brand videos locally
- [ ] **Release process** — tag v1.0.0 with `elevate-web-starter` included

## Next

- [ ] **UI component library** — extract the design system into a reusable, tree-shakeable package
- [ ] **Auth starter** — Supabase auth boilerplate with signup/login/reset + session guard
- [ ] **Blog starter** — markdown-powered blog with syntax highlighting, ready to deploy
- [ ] **Analytics dashboard template** — KPI cards, charts and tables using the brand design system
- [ ] **Discussion forum** as a standalone starter

## Later

- [ ] **Flutter / Android starter** — with a small Kotlin + Compose sample (TrackSpend patterns)
- [ ] **API wrapper + CLI** — a tiny typed client for common Supabase patterns, and a scaffold CLI
- [ ] **Case-study templates** — portfolio/agency templates built from the brand platform
- [ ] **Translations** — starter docs in Spanish, French, Kiswahili

## How to influence this

Open an issue or discussion marked `roadmap` with your idea. Highest-value ideas get pulled up
the list — especially ones that make the repo more useful to more developers.
